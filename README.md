A tiny Node program that writes one short text to `/output/entry.txt` — a loading-screen tip for stressed developers and AI coding agents: if the build has been "almost done" for 40 minutes, it is not almost done. Go drink water. The error log will still be there. Sharp, funny, and real advice, landing mid-build. 130 characters, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
